# LiteratureCraft — DDLC Mod

A small Doki Doki Literature Club! fan-mod story that introduces the LiteratureCraft idea: turning the club's writing into a world they can build together.

## Install

1. Make a backup of your DDLC installation.
2. Download `game/literaturecraft_mod.rpy` from this repository.
3. Open your DDLC installation folder and open its `game` folder.
4. Copy `literaturecraft_mod.rpy` into that `game` folder.
5. Launch DDLC.
6. To start the mod scene, the label is `literaturecraft_start`. If you are using a DDLC mod launcher/template that provides a mod script entry point, call that label from the mod's startup script.

### Important

This is source code only. It does not include DDLC's copyrighted game files or assets. Use it with a legitimate copy of DDLC and follow DDLC's current fan-content/modding guidelines.

## What it adds

- A LiteratureCraft opening scene.
- Dialogue for Sayori, Monika, Natsuki, and Yuri.
- Two choices: build the club house or ask Monika about the plan.
- No bundled copyrighted DDLC assets.
